csTimer to Cubic Timer

Converts all your csTimer sessions into one backup file that Cubic Timer or Twisty Timer can restore. The file stays on your device. Nothing is uploaded.

1. Export from csTimer

  1. Open cstimer.net on the device that has your times.
  2. Click the EXPORT button.
  3. Click Export to file. csTimer saves a file named like cstimer_20261011_101500.txt.

2. Open the csTimer file

3. Check the sessions

Each csTimer session becomes a category under a puzzle. Change the puzzle or the category name if you want.

csTimer sessionSolvesPuzzleCategory

4. Restore on your phone

  1. Copy the backup file to your phone.
  2. In Cubic Timer or Twisty Timer, open the side menu and tap Export/Import.
  3. Tap Import…, then From backup, and choose the file.

If you restore the same file twice, the app ignores the solves it already has. If you change a puzzle or category name between two restores, the app adds those solves again.
